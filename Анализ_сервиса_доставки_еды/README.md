# Проект: Сервис доставки еды

## Цель проекта
Проанализировать ключевые метрики: динамику DAU, CR, среднего чека, Retention Rate и LTV сервиса доставки еды «Всё.из.кафе» в Саранске за период с 1 мая по 30 июня 2021 года. Выявить тренды и аномалии по каждой метрике (пики, спады, стабильность). Сформулировать причины отклонений и рекомендации по улучшению показателей
